# 🛒 Electrox — PHP E-Commerce Platform

Electrox is a full-featured e-commerce web application built with PHP. It provides a complete online shopping experience including product browsing, cart management, and order handling.

## 🚀 Features

- Product listing and detail pages
- Shopping cart functionality
- User authentication (register/login)
- Order management
- Admin panel for product and order management
- Responsive design for mobile and desktop

## 🛠️ Tech Stack

- **Language:** PHP
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL

## ⚙️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/09kris/Electrox.git
   cd Electrox
   ```

2. **Extract the project files**
   ```
   Unzip Ecommerce-main.zip into your web server directory (e.g., htdocs or www)
   ```

3. **Set up the database**
   - Create a MySQL database
   - Import the provided SQL file (if available)
   - Update the database credentials in the config file

4. **Configure your web server**
   - Use XAMPP, WAMP, or any PHP-compatible server
   - Point the document root to the project folder

5. **Run the application**
   - Open your browser and navigate to `http://localhost/Electrox`
